# Brainstorming Workflow

## Goal

Turn a vague idea into a ready-to-execute project without prematurely locking into implementation.

## Loop

```text
Frame → Expand → Challenge → Research → Converge → Ready
```

### Frame
Clarify:
- problem
- user/context
- desired outcome
- constraints

### Expand
Generate multiple solution shapes without ranking them.

### Challenge
Surface assumptions, failure modes, trade-offs, and missing information.

### Research
Use external sources when the answer depends on current, niche, or documented facts.

### Converge
Reduce the solution space and record explicit decisions.

### Ready
Produce a project brief and a first milestone.

## Persistent idea state

```text
.clae/ideas/<idea-id>/
├── canvas.md
├── research.md
└── decisions.md
```

This preserves the useful state without replaying the conversation.

## Ready gate

The idea is ready when it has:

- a clear problem;
- target user/context;
- first use case;
- non-goals;
- constraints;
- a chosen direction plus alternatives considered;
- first milestone;
- success signal;
- major risks / unknowns.
