# Design-aware Coding Rules

- Reuse existing components before creating new ones.
- Reuse existing tokens/variables before adding new values.
- Keep visual constants out of business logic.
- Implement loading, empty, and error states when the feature requires them.
- Do not silently invent a new interaction pattern when an existing one is available.
