# Design DNA

Do not persist only images. Persist the constraints that make the visuals consistent.

```text
.clae/design/<asset-id>/
├── dna.yaml
├── references/
└── decisions.md
```

Capture:
- silhouette / proportion
- palette
- materials
- typography or icon language when relevant
- style descriptors
- interaction or motion constraints when relevant
- explicit avoid list

The goal is to make a later generation reference a stable visual language instead of inventing a new style.
