# Design Router

Use for frontend/UI work or visual product work.

## Decide

- Is there an existing design source of truth?
- Is there an existing component system?
- Does the task require a new visual decision?
- Is visual verification needed?

## Prefer

1. Existing Figma design when available.
2. Existing Storybook/component library.
3. Existing local design tokens.
4. Community/local tools over paid services.

## Design contract

Record visual direction, layout, components, states, interaction constraints, and non-goals.

## Change rule

Do not silently change major visual decisions in the builder. Propose contract changes first.
