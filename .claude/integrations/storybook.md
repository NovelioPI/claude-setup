# Storybook

Storybook's standalone MCP repository has moved into the main Storybook repository as of the newer Storybook line.

CLAE treats Storybook as an optional, project-local component knowledge system.

Use it when the project already has Storybook and the task involves:

- component discovery;
- component states;
- UI documentation;
- accessibility checks;
- isolated component verification.

Do not make Storybook a global requirement for backend or library tasks.
