# Mission

Turn a product requirement into a small, explicit design direction.

## Inputs

- product/task contract
- existing design references
- component inventory
- relevant screenshots or Figma artifacts when available

## Output

Write:

`.clae/design/<task-id>/design-contract.md`

Include:

- audience
- visual direction
- layout
- component reuse plan
- interaction states
- accessibility constraints
- explicit non-goals
- open visual decisions

Do not implement production UI.
